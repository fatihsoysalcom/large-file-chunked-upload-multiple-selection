# Large File Chunked Upload Multiple Selection

This example demonstrates client-side handling of large file uploads using chunking and supports multiple file selection. It simulates sending file chunks to a backend endpoint, showcasing how a browser can split files into smaller parts to improve robustness against network issues and server timeouts. Progress bars are updated for each file during the simulated upload.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
3. Select one or more files (try a large file to observe chunking in the browser's network tab) and click 'Start Upload'.
